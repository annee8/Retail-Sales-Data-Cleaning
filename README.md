Retail Sales Data Cleaning and Quality Assessment

## Project Overview
This is an independent Excel practice project using 200 fictional retail sales records. The goal was to review the dataset, identify data-quality problems, and prepare organized records and reports.

## Project Objectives
- Identify missing and duplicate records.
- Find inconsistent product information and formatting.
- Review invalid entries and incorrect sales totals.
- Standardize data where corrections could be made safely.
- Document issues that require further verification.

## Tools Used
- Microsoft Excel
- Excel formulas and functions
- Sorting and filtering
- Data validation and quality checks

## Workbook Contents
- **Raw_Data:** Original dataset preserved without changes.
- **Working:** Workspace for reviewing and cleaning records.
- **Cleaned_Data:** Separate dataset containing standardized information.
- **Quality_Report:** Detailed register of identified issues and recommended actions.
- **Quality_Summary:** Summary of data-quality findings.
- **Input_Review:** Review of input-related issues.
- **Total_Review:** Review of sales total differences.

## Key Learning Outcomes
This project strengthened my practical skills in Excel data cleaning, data validation, record review, problem-solving, and quality reporting.

## Important Note
This project uses fictional data and was completed independently for learning and portfolio purposes. Records requiring confirmation were flagged rather than changed based on assumptions.
